# 🌗 3D Portfolio — Day & Night

An interactive **React Three Fiber** portfolio that represents my professional duality:

- ☀️ **Day** — Accountant
- 🌙 **Night** — Developer

Users can switch between day and night to explore both worlds inside a 3D scene.
